# PNJ conocidos

Este archivo reúne únicamente a personajes que el grupo haya conocido, investigado o sobre los que disponga de información fiable o rumores identificados como tales.

## Índice

*Todavía no hay expedientes públicos.*

### Formato de cada expediente

Cada PNJ podrá incluir su **primera aparición**, **facción**, **relación con el grupo**, **estado conocido**, **lugares relacionados** y una cronología breve de encuentros.

Los datos mecánicos reservados al Director no aparecerán en esta wiki.
